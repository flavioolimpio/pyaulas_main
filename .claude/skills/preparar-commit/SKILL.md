# Preparar commit

## Objetivo

Ajudar a revisar alterações antes de commit, organizar arquivos modificados e sugerir uma mensagem de commit clara.

## Procedimento

1. Verifique quais arquivos foram modificados.
2. Identifique alterações principais.
3. Aponte arquivos que parecem não relacionados.
4. Sugira testes ou comandos de verificação.
5. Escreva uma mensagem de commit objetiva.

## Estilo da mensagem

Use mensagens curtas, no imperativo ou em português claro.

Exemplos:

- Adiciona página de aulas experimentais
- Corrige navegação lateral do Streamlit
- Organiza materiais de Química Geral

## Saída esperada

Apresente resumo das mudanças, riscos, testes recomendados e sugestão de mensagem de commit.
