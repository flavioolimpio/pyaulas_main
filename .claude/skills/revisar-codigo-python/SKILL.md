# Revisar código Python

## Objetivo

Revisar código Python com foco em correção, clareza, manutenção e segurança.

## Procedimento

1. Leia os arquivos relevantes antes de sugerir alterações.
2. Identifique erros de sintaxe, imports faltantes e variáveis indefinidas.
3. Verifique se há duplicação ou funções muito longas.
4. Prefira mudanças pequenas e testáveis.
5. Explique qualquer alteração que possa mudar comportamento.
6. Não adicionar dependências novas sem necessidade.

## Checklist

- O código executa?
- Os imports estão corretos?
- Os nomes são claros?
- Há repetição evitável?
- Há tratamento de erro quando necessário?
- Há risco de apagar dados?
- O código continua compatível com Streamlit?

## Saída esperada

Forneça problemas encontrados, correções recomendadas, código corrigido e comandos para testar.
